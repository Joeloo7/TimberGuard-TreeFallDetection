# 🌲 TimberGuard — AI-Driven Tree Fall Risk Prediction System

An AI-powered system designed to assess the risk level of tree fall hazards using a combination of **Computer Vision**, **Deep Learning**, and **Web Technologies**. TimberGuard helps provide proactive environmental safety insights.

---

## 🚀 Tech Stack

| Technology | Usage |
|----------|-------|
| **Python** | Core backend logic & ML integration |
| **Django** | Backend framework & API endpoints |
| **TensorFlow (CNN)** | Tree disease classification from leaf image |
| **OpenCV** | Tree inclination detection & image preprocessing |
| **SVM Model** | Risk scoring and hazard prediction |
| **HTML, CSS, JS, Bootstrap** | UI development |
| **MySQL / SQLite** | Database storage |

---

## 🎯 Key Features

✔ Detects **tree disease** using a trained CNN model  
✔ Measures **tree inclination** using OpenCV image analysis  
✔ Calculates **fall risk score** using SVM classifier  
✔ User-friendly web interface  
✔ Real-time prediction & actionable output
